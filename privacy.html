Действует с 1 октября 2026 года

«Финансовый помощник» — личный Telegram-бот для учёта денег. Он работает по приглашениям. Здесь описано, какие данные он использует и где они хранятся.

1. Доступ к Google

При подключении вы разрешаете боту доступ уровня drive.file. Это значит, что бот может создать на вашем Google Диске одну таблицу «Финансы» и работать только с ней. Остальные ваши файлы, почта, контакты и другие данные Google боту недоступны.

2. Где хранятся ваши данные

  • Финансовые записи (счета, операции, долги, платежи, цели, история переписки с ботом) хранятся только в вашей таблице на вашем Google Диске.
  • На сервере бота хранится минимум для работы: ваш Telegram ID, имя, ссылка на таблицу и ключ доступа Google к этой таблице (refresh token).

3. Обработка сообщений

Чтобы понять сообщение и ответить, бот передаёт текст, голосовые сообщения и фотографии, которые вы ему отправляете, а также нужные для ответа данные из вашей таблицы в сервис OpenAI. Сообщения доставляются через Telegram. Мы не продаём и не передаём ваши данные третьим лицам для рекламы или других целей.

4. Использование данных Google

Данные, полученные через API Google, используются только для того, чтобы вести вашу таблицу и отвечать вам в боте. Использование и передача информации, полученной от API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

5. Как отключиться и удалить данные

  • Команда /disconnect в боте отключает таблицу и удаляет ключ доступа с сервера.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions → «Финансовый помощник» → удалить доступ.
  • Таблица остаётся вашей: её можно удалить с Google Диска как обычный файл.
  • Чтобы удалить и остальные сведения о вас с сервера, напишите на почту ниже.

Privacy Policy (English)

Financial Assistant is an invite-only personal Telegram bot for budgeting. Effective October 1, 2026.

Google access. The bot requests only the https://www.googleapis.com/auth/drive.file scope. It creates one spreadsheet in the user's Google Drive and can access only files it created. It cannot see other files, email or contacts.

Data storage. Financial records and chat history are stored only in the user's own spreadsheet. The bot's server stores the user's Telegram ID, name, spreadsheet link and the Google refresh token for that spreadsheet.

Processing. Messages, voice notes and photos the user sends, together with the spreadsheet data needed to answer, are processed by OpenAI to generate replies, and delivered via Telegram. Data is not sold or shared for advertising.

Limited Use. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion. Users can run /disconnect, revoke access at myaccount.google.com/permissions, delete the spreadsheet, or email jargaljargalsid@gmail.com to remove remaining data.
